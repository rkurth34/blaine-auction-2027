# Blaine 2027 auction tools

Static pages served by Vercel. Every page reads and saves through the Apps Script web app in `gas/Code.gs`, which is bound to the "Blaine 2027 Auction Data" Google Sheet.

- `/` Auction HQ
- `/contacts/` Contacts
- `/tracker/` 2027 procurement tracker

The team passcode lives in the Apps Script project's Script Properties (PASSCODE), never in this repo.
